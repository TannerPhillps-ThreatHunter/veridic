# Veridic Lineage

## FieldFrame

Veridic originated as the experimental project **FieldFrame**.

FieldFrame established the initial research results:

1. Field semantics are layered rather than reducible to storage dtype.
2. Classification can be modeled as:

       Category -> Kind -> Type

3. Scale, Unit, and Role possess independent computational significance.
4. Operations can be admitted or rejected semantically.
5. Operations can derive the semantics of their outputs.
6. Value participates in execution rather than static Field identity.
7. Invariants participate in contextual validity.
8. A semantically valid result may still be contextually false.

The transition to **Veridic** marks the point at which the research target
expanded beyond a semantic DataFrame.

## Veridic

Veridic is a semantic computation system concerned with three distinct
questions:

    Can it be computed?

    Does the computation have meaning?

    Does the result remain truthful in context?

FieldFrame remains the experimental lineage from which Veridic emerged.
