# Prior Art

Research areas to track:

- ISO/IEC 11179 metadata registries
- PMML DataDictionary / MiningSchema
- measurement theory and NOIR
- representational measurement theory
- QUDT
- FHIR ElementDefinition
- Apache Arrow extension types and metadata
- Pandera
- Pint / Pint-Pandas
- Ibis
- Polars
- refinement types
- semantic and dependent type systems
- DataFrame formal semantics

Novelty should not be claimed merely from combining:

    Type + Scale + Role + Unit + Constraints

The stronger research question is whether layered Field semantics can
compositionally determine:

    operation admission
    result semantic derivation
    invariant preservation
